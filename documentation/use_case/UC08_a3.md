# UC08 - A3 Module Tools (`ontobdc a3`)

## Description
This use case exposes the A3 framework tools to the user. It allows the extraction, transformation, and loading (ETL) of data from various sources (files or URLs) into the OntoBDC stack, acting as the primary integration layer for the A3 module.

## Actors
- **User**: Needs to perform ETL operations using the A3 framework.
- **System (OntoBDC)**: Orchestrates the A3 module, validating arguments, processing the requested sources, and triggering the ETL pipeline.

## Pre-conditions
- The project is initialized.
- The A3 module is enabled in the environment configuration (`ontobdc extra --enable a3`).

## Flow of Events
1. The user runs `ontobdc a3` or `ontobdc a3 --help`.
2. The system verifies if the A3 module is enabled. If not, it warns the user to enable it.
3. If enabled, the system displays the formatted help menu, detailing available commands such as `--etl`.
4. The user runs `ontobdc a3 --etl --source <file|url>`.
5. The system validates the presence of the mandatory `--source` argument.
6. If the `--source` is missing, the system outputs a styled error message indicating the required argument and providing an example.
7. If the `--source` is provided, the system delegates the extraction, transformation, and loading logic to the A3 ETL pipeline for the given file or URL.
8. The system executes the pipeline and reports the outcome to the user.

## Post-conditions
- The ETL process is executed for the specified source, integrating the data into the system.
